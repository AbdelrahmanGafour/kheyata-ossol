# قالب ووردبريس — للخياطة أصول

قالب ووردبريس مخصص بالكامل، مبني على تصميم الموقع الثابت الأصلي بنفس نظام التصميم (الألوان، الخطوط، المكوّنات)، مع:

- **WooCommerce** — المتجر وإدارة المنتجات والطلبات (منتجات بسيطة + منتج متغيّر بمقاسات).
- **Contact Form 7** — نموذج "تواصل معنا"، بنفس تصميم النموذج الأصلي تمامًا.
- **Yoast SEO** — Schema تلقائي للمؤسسة، breadcrumbs، قوالب عناوين المتجر.
- **Secure Custom Fields (SCF)** — كل نص/صورة/فيديو في الصفحة الرئيسية وصفحة "من نحن" وصفحة "تواصل معنا" قابل للتحرير من لوحة التحكم.
- **لوحة "خيارات القالب"** مبنية يدويًا بأسلوب Woodmart (10 تبويبات: عام / الهيدر / الفوتر / الألوان / الخطوط / المتجر ونمط العرض / صفحة المنتج / التواصل / الأداء / كود مخصص) — عبر WordPress Settings API مباشرة، بدون أي مكتبة خارجية (إطار Woodmart الحقيقي "XTS" إطار مملوك، لا يمكن استخدامه). كل شيء عام (ألوان، خطوط، نمط عرض المنتجات) يُضبط من هنا ويُطبَّق على كامل الموقع فورًا.
- **مثبّت إضافات بضغطة واحدة** + **مستورد محتوى تجريبي** ينشئ نفس محتوى الموقع الأصلي كاملاً (تصنيفات + منتجات + صفحات ديناميكية + قائمة تنقّل) تلقائيًا.
- **سلة منزلقة (Mini Cart)**، **معاينة سريعة للمنتج (Quick View)**، و**شريط "أضف للسلة" ثابت على الموبايل** — كلها قابلة للتفعيل/الإيقاف من خيارات القالب.

القالب **عربي/RTL فقط** بقرار صريح — لا يوجد دعم للغات أخرى ولا Polylang.

---

## 1) التثبيت (الطريق الأسرع: بضغطتين فقط)

1. ثبّت ووردبريس (نسخة 6.4 فأكثر، PHP 7.4 فأكثر، ويُفضَّل PHP 8+ لدعم `color-mix()` في بعض تأثيرات الألوان).
2. ارفع مجلد `kheyata-ossol` (هذا المجلد) إلى `wp-content/themes/` وفعّله من: مظهر ← القوالب.
3. فور التفعيل يظهر تنبيه بالإضافات المطلوبة الناقصة، أو اذهب مباشرة إلى: **خيارات القالب ← الإضافات المطلوبة**. اضغط "تثبيت الآن" ثم "تفعيل" لكل من:
   - **WooCommerce**
   - **Contact Form 7**
   - **Yoast SEO**
   - **Secure Custom Fields** (SCF — نسخة ووردبريس.org الرسمية من ACF، مجانية بالكامل)
4. بمجرد تفعيل الإضافات الأربع، **يبدأ استيراد المحتوى التجريبي تلقائيًا** (لا حاجة لأي إجراء إضافي) — أو فعّله يدويًا من: **خيارات القالب ← استيراد محتوى تجريبي**. هذا ينشئ دفعة واحدة:
   - 6 تصنيفات منتجات بأيقوناتها.
   - 10 منتجات حقيقية بصورها الأصلية (منها منتج متغيّر بثلاث مقاسات/أسعار).
   - 3 صفحات مكتملة المحتوى: **الرئيسية** (مضبوطة تلقائيًا كصفحة رئيسية ثابتة) و**من نحن** و**تواصل معنا** — بكل نصوصها وصورها مطابقة للموقع الأصلي.
   - قائمة تنقّل جاهزة ومربوطة بالهيدر والقائمة المنسدلة على الموبايل.
   - طريقة دفع "الدفع عند الاستلام" (COD) مفعّلة تلقائيًا في WooCommerce.
   - نموذج Contact Form 7 افتراضي مطابق لحقول التصميم الأصلي، مربوط تلقائيًا بخيارات القالب.
   - إعدادات breadcrumbs وقوالب عناوين مقترحة في Yoast SEO.
5. من: الإعدادات ← الروابط الدائمة، اختر "اسم المقالة" (Post name) لضمان روابط نظيفة.

> إعادة الاستيراد آمنة (لا تُنشئ تكرارًا لعناصر بنفس SKU/العنوان)، متاحة يدويًا في أي وقت من نفس الصفحة.

## 2) استيراد بديل عبر CSV (اختياري)

إن كنت تفضّل استيراد المنتجات يدويًا بدل الاستيراد التلقائي أعلاه، ملف جاهز في: `woocommerce-import/products.csv` — يُستورد من: المنتجات ← استيراد. **الصور في هذه الحالة غير مرفقة تلقائيًا** (ارفعها من `assets/images/products/` عبر الوسائط ← أضف جديد، ثم أرفقها يدويًا بكل منتج). المستورد التلقائي في القسم (1) أعلاه يرفق الصور تلقائيًا فلا داعي لهذا الملف إلا لو أردت التحكم اليدوي الكامل.

## 3) صفحات WooCommerce الأساسية

من: WooCommerce ← الإعدادات ← عام، تأكد من ضبط:
- صفحة المتجر (Shop) — يستخدمها القالب تلقائيًا عبر `archive-product.php`.
- صفحة السلة — مُصمَّمة ببطاقات منتج مطابقة تمامًا لتصميم الموقع الأصلي (`woocommerce/cart/cart.php`)، وليست جدولاً افتراضيًا.
- صفحة الدفع وصفحة "حسابي" — تُنشآن تلقائيًا عند تفعيل WooCommerce، وتُعرضان عبر `page.php` مع طبقة تنسيق كاملة تحاكي تصميم الموقع (الفوتر يتحول تلقائيًا للنسخة المبسّطة في هذه الصفحات الثلاث).
- العملة: جنيه مصري (EGP) — رمز العملة يظهر كـ"ج.م" تلقائيًا (مضبوط بالقالب).
- الشحن: أنشئ منطقة شحن لمصر بطريقة شحن "سعر ثابت" (Flat rate) — القيم المقترحة (تكلفة الشحن، وحد الشحن المجاني) موجودة في تبويب "المتجر" بخيارات القالب لعرضها فقط؛ اضبط نفس القيمتين فعليًا في إعدادات الشحن بـ WooCommerce.
- طرق الدفع: فعّل "الدفع عند الاستلام" فقط (مفعّلة تلقائيًا عند أول تفعيل للقالب)، وعطّل باقي الطرق (بطاقات/تحويل بنكي) إن كنت تريد نفس تجربة الموقع الأصلي (COD فقط).
- **مهم**: من الإعدادات ← عام، اضبط لغة الموقع (Site Language) على "العربية" حتى تُترجم نصوص WooCommerce الأساسية غير المخصصة في القالب (مثل "أضف للسلة" الافتراضي في بعض الحالات الحدّية) تلقائيًا عبر ملفات ترجمة WooCommerce الرسمية.

## 4) لوحة "خيارات القالب" (إعدادات عامة على مستوى الموقع بالكامل)

من القائمة الجانبية: **خيارات القالب** (أيقونة فرشاة). كل قيمة هنا تُطبَّق فورًا على كل صفحات الموقع والمتجر:

| التبويب | يضبط |
|---|---|
| عام | الشعار، Preloader، زر العودة للأعلى، زر واتساب العائم، استدارة زوايا البطاقات |
| الهيدر | هيدر ثابت، ارتفاعه، إظهار أيقونتي الحساب/السلة، زر دعوة إضافي |
| الفوتر | نوع الفوتر الافتراضي، نص "عن المتجر"، نص الحقوق |
| **الألوان** | 16 لونًا عامًا: الأساسي/التمييز بدرجاتهما، خلفيات الموقع، ألوان النصوص، خلفية الهيدر، خلفية ونص الفوتر، لون السعر، لون شارة الخصم، لون واتساب |
| **الخطوط** | خط العناوين/النصوص/الأرقام (اختيار بين El Messiri / Tajawal / Cairo / Almarai / DM Sans)، حجم الخط الأساسي، أحجام H1/H2/H3 |
| المتجر ونمط العرض | عدد الأعمدة، عدد المنتجات بالصفحة، شكل الفلاتر، تكبير الصورة عند المرور، إظهار التقييم/التصنيف في البطاقة، نص شارة الخصم، نص "نفدت الكمية"، الشحن، المنتجات ذات الصلة |
| صفحة المنتج | شارة المخزون، صف مزايا الثقة (نصوصها الأربعة) |
| التواصل والسوشيال ميديا | الهاتف، واتساب، البريد، نطاق الخدمة، روابط السوشيال ميديا، **معرّف نموذج Contact Form 7** |
| الأداء | تعطيل الإيموجي/oEmbed الافتراضيين، Lazy load |
| **كود مخصص** | CSS/JavaScript مخصص يُضافان لكل صفحات الموقع (لأي تخصيص دقيق لا تغطيه الخيارات أعلاه) |

## 5) المحتوى الديناميكي (Secure Custom Fields)

- **الصفحة الرئيسية**: اذهب لتعديل الصفحة المضبوطة كـ"صفحة رئيسية ثابتة" (الإعدادات ← القراءة) — ستجد صندوق حقول "محتوى الصفحة الرئيسية" بكل تبويبات: الهيرو (فيديو/صورة/عنوان/أزرار/إحصائيات)، التصنيفات، أحدث المنتجات، خدماتنا، منتجات مميزة، خطوات الطلب، CTA الأكاديمية، آراء العملاء.
- **صفحة "من نحن"**: أنشئ صفحة جديدة، واختر من "قالب الصفحة" (Page Attributes) قيمة **"صفحة من نحن"** — سيظهر صندوق حقول "محتوى صفحة من نحن" (القصة، لماذا تختارنا، ركائزنا، الإحصائيات، الاقتباس، CTA ختامي).
- **صفحة "تواصل معنا"**: أنشئ صفحة جديدة، واختر قالب **"صفحة تواصل معنا"** — سيظهر صندوق "محتوى صفحة تواصل معنا" (نبذة البطاقة، الأسئلة الشائعة). بيانات التواصل الفعلية (الهاتف/واتساب/البريد) تأتي من خيارات القالب ← تبويب التواصل، والنموذج نفسه من Contact Form 7 المربوط تلقائيًا.
- فيديو الهيرو: ملف MP4 الأصلي موجود في `assets/images/hero/HeroVideo.mp4` — ارفعه من حقل "فيديو الخلفية" في محتوى الصفحة الرئيسية (أو اربطه مباشرة عبر رابط الملف بعد رفعه للوسائط).

## 6) القوائم

من: مظهر ← القوائم، أنشئ قائمة وعيّنها لموضع **"القائمة الرئيسية (الهيدر)"**. حتى يتم إنشاؤها، يعرض الهيدر قائمة احتياطية تلقائية (الرئيسية / المتجر / من نحن / تواصل معنا) فتعمل الواجهة من أول لحظة بدون إعداد إضافي. (مستورد المحتوى التجريبي في القسم 1 ينشئ هذه القائمة تلقائيًا أيضًا.)

## 6.5) ميزات تسوّق إضافية (اختيارية، مفعّلة افتراضيًا)

| الميزة | كيف تعمل | إيقافها من |
|---|---|---|
| **السلة المنزلقة (Mini Cart)** | الضغط على أيقونة السلة في الهيدر يفتح لوحة جانبية بمحتوى السلة فورًا (عبر AJAX Fragments) بدل الانتقال لصفحة منفصلة، مع أزرار "عرض السلة"/"إتمام الطلب". تفتح تلقائيًا أيضًا بعد أي عملية "أضف للسلة" ناجحة. | خيارات القالب ← الهيدر ← "فتح سلة منزلقة" |
| **المعاينة السريعة (Quick View)** | زر عين 👁 يظهر عند المرور فوق أي بطاقة منتج، يفتح نافذة منبثقة بصورة المنتج وسعره ونموذج "أضف للسلة" الحقيقي (بما فيه التنويعات) دون مغادرة الصفحة. | خيارات القالب ← المتجر ونمط العرض ← "إظهار زر المعاينة السريعة" |
| **شريط "أضف للسلة" الثابت (موبايل)** | على صفحة المنتج، بمجرد أن يمرّر الزائر لأسفل بحيث يختفي زر "أضف للسلة" الأصلي عن الشاشة، يظهر شريط مصغّر ثابت أسفل الشاشة (صورة + اسم + سعر + زر) — يُفعِّل نفس الزر الأصلي عند الضغط (بما يشمل أي تنويعة مُختارة). سطح المكتب غير متأثر. | خيارات القالب ← صفحة المنتج ← "شريط أضف للسلة الثابت" |

كل الميزات الثلاث مبنية فوق دوال WooCommerce الأصلية (Fragments API، نماذج الإضافة للسلة القياسية) وليست إعادة بناء مستقلة لمنطق السلة/التسعير، حفاظًا على دقة الحسابات في كل الحالات.

## 7) Yoast SEO — أفضل تهيئة لمتجر إلكتروني

- المخطط البنيوي (Schema) لمنظمة المتجر (الهاتف، الشعار، روابط السوشيال ميديا) يُبنى تلقائيًا من بيانات خيارات القالب — لا تكرر إدخالها في Yoast.
- من: Yoast SEO ← الإعدادات ← المتجر الإلكتروني، فعّل "Enhanced" لبيانات المنتج المنظمة (schema.org/Product) — تفعيل تلقائي عند تفعيل الإضافة مع WooCommerce نشِط.
- الخرائط: تأكد من ظهور `sitemap_index.xml` (مفعّل افتراضيًا في Yoast) وأضفه في Google Search Console.
- Breadcrumbs: مفعّلة تلقائيًا (`shortcode`/`yoast_breadcrumb()`) ومربوطة بتصميم `.breadcrumb` في كل صفحة.

## 8) ⚠️ ملاحظة مهمة: تسجيل الدخول برقم الهاتف

الموقع الثابت الأصلي كان يستخدم تسجيل دخول/تسجيل بـ**رقم الهاتف + رمز تحقق OTP تجريبي**. **هذا غير مطلوب في قائمة الإضافات المطلوبة لهذا القالب**، ولذلك تستخدم صفحة "حسابي" نظام WooCommerce/ووردبريس الافتراضي (بريد إلكتروني/اسم مستخدم + كلمة مرور) — وهو النظام الآمن والمُختبر افتراضيًا.

إن كنت تريد تسجيل دخول حقيقي برقم الهاتف عبر رسائل SMS فعلية، هذا يتطلب:
- إضافة تسجيل دخول بالهاتف متوافقة مع WooCommerce (مثل "WP OTP Login" أو مكوّن SMS مشابه)، أو تطوير مخصص.
- حساب مع مزوّد رسائل SMS حقيقي (مثل Twilio أو مزوّد محلي في مصر) لإرسال الرموز.

هذا خارج نطاق الإضافات الأربع المطلوبة، ولم يُبنَ افتراضيًا حتى لا يُوهم بوجود نظام OTP فعلي لا يعمل حقًا.

## 9) ما لم يُنسخ بالضبط (اختلافات معروفة عن الموقع الثابت)

- **معرض صور المنتج**: يستخدم معرض WooCommerce الأصلي (Flexslider، مع تفعيل التكبير والعرض المنبثق) بدل الصور المصغّرة المخصصة، منسّق بنفس ألوان/زوايا القالب. وظيفيًا مطابق، بصريًا قريب جدًا وليس نسخة بكسل بكسل.
- **منتقي المقاسات**: أزرار Pill حقيقية (`assets/js/shop.js`) لكنها تتحكم في قائمة WooCommerce الأصلية خلف الكواليس (لضمان صحة حساب السعر/التوفر بدل إعادة بناء منطق WooCommerce من الصفر).
- **صفحة الدفع (Checkout)**: لم تُستبدل بالكامل عمدًا (بخلاف السلة) — قوالب الدفع الافتراضية في WooCommerce حساسة (nonces، تكامل بوابات الدفع، إضافات أخرى تعتمد على خطافاتها الأصلية)، فتم الاكتفاء بتنسيقها بالكامل عبر CSS دون تغيير بنيتها، حفاظًا على عمل الدفع بشكل صحيح 100%.
- لا يوجد ملف `screenshot.png` (معاينة القالب في مظهر ← القوالب) — أضِف لقطة شاشة 1200×900px باسم `screenshot.png` في جذر القالب متى توفرت بيئة لالتقاطها.

```
kheyata-ossol/
  style.css                     ← رأس القالب + نظام التصميم الكامل + طبقة توافق WooCommerce/CF7

  header.php / footer.php       ← الهيدر/الفوتر الموحّدان
  front-page.php                ← الصفحة الرئيسية (ديناميكية بالكامل عبر SCF)
  page-about.php                ← قالب صفحة "من نحن"
  page-contact.php              ← قالب صفحة "تواصل معنا" (Contact Form 7)
  page.php                      ← صفحات عامة + دفع/حسابي (WooCommerce)
  archive-product.php           ← صفحة المتجر (فلاتر + شبكة منتجات)
  single-product.php            ← صفحة تفاصيل المنتج
  woocommerce/content-product.php ← بطاقة منتج موحّدة (رئيسية + متجر)

  inc/theme-options/            ← لوحة خيارات القالب (Settings API يدوي، أسلوب Woodmart)
  inc/scf-fields.php            ← كل حقول Secure Custom Fields
  inc/woocommerce.php           ← تكامل WooCommerce
  inc/contact-form7.php         ← تكامل Contact Form 7
  inc/yoast-seo.php             ← تكامل Yoast SEO
  inc/template-tags.php         ← دوال مساعدة مشتركة
  inc/plugin-installer.php      ← مثبّت الإضافات المطلوبة بضغطة واحدة
  inc/demo-import.php           ← مستورد المحتوى التجريبي (تصنيفات + منتجات + صفحات + قائمة)
  inc/quick-view.php            ← معالج AJAX للمعاينة السريعة
  assets/js/mini-cart.js        ← منطق فتح/إغلاق السلة المنزلقة
  assets/js/quick-view.js       ← منطق نافذة المعاينة السريعة
  assets/js/shop.js             ← فلاتر المتجر + منتقي التنويعات + شريط أضف للسلة الثابت
  assets/                       ← CSS مصدره، JS، الخطوط الخارجية (GSAP/anime.js/Font Awesome)، الصور الأصلية
  woocommerce-import/products.csv ← بديل استيراد يدوي عبر CSV (اختياري، انظر القسم 2)
```
